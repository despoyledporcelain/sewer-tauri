# seWer Tauri

seWer — музыкальный плеер для Windows на Tauri v2, React и Vite. Поддерживает локальную библиотеку и SoundCloud. При изменениях сохраняй непрерывность воспроизведения, работу очереди и совместимость сохранённых настроек. Для интерфейса сверяйся с `PRODUCT.md` и сохраняй русскую и английскую локализации.

## Проверка изменений

- Пользователь сам проверяет интерфейс и поведение в окне, запущенном через `npm run app:dev`. Считай, что сеанс уже может работать. Оставляй его запущенным и согласовывай перезапуск, если он нужен. Для ручной проверки кратко укажи экран, действие и ожидаемый результат.
- Автоматически запускай подходящие проверки. `npm test` запускает тесты из `tools/`, `npm run build` собирает фронтенд, а `cargo check --manifest-path src-tauri/Cargo.toml` проверяет Rust. Сообщай, какие проверки прошли и какие ошибки были уже до изменений.
- `npm run app:build` собирает релизный пакет Tauri. Используй его, когда задача затрагивает упаковку или требует готовой сборки.

## Карта проекта

- `src/main.jsx` — точка входа React. `src/app.jsx` — экраны, состояние плеера и основная логика воспроизведения. Профильные модули и стили лежат рядом в `src/`, статические ресурсы — в `public/`.
- `src/bridge.js` связывает фасад `window.electronAPI` с командами и событиями Tauri. При изменении IPC проверяй обе стороны, включая регистрацию команд в `src-tauri/src/lib.rs`.
- `src-tauri/src/` — нативная часть, включая локальную библиотеку, настройки, загрузки, SoundCloud и Discord. Конфигурация Tauri — в `src-tauri/tauri.conf.json`, NSIS-установщик — в `src-tauri/installer/`.
- `workers/listening-party/` — серверная часть совместного прослушивания. Клиентские модули комнаты находятся в `src/`.
- `dist/`, `node_modules/`, `src-tauri/target/` и `release/` содержат зависимости и результаты сборок. Для изменений приложения начинай с исходников.
