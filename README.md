# seWer

Музыкальный плеер для Windows. SoundCloud и локальная музыка в одной библиотеке.

**[Скачать для Windows](https://github.com/despoyledporcelain/sewer-tauri/releases/latest)** · Windows 10 и 11 · x64

![Плеер seWer с открытой библиотекой и обложкой текущего трека](docs/screenshot.png)

## Возможности

- **SoundCloud** · лайки, поиск, плейлисты и загрузка треков.
- **Воспроизведение** · эквалайзер, кроссфейд, скорость и тон, тексты песен.
- **Комнаты** · совместное прослушивание с синхронизацией.
- **Интеграция с Windows и Discord** · трей, горячие клавиши и Rich Presence.

## Разработка

Tauri v2, React и Rust. Для сборки нужны Node.js 18+, Rust и MSVC Build Tools.

```powershell
npm ci
npm run app:dev
```

`npm test` запускает тесты. `npm run app:build` собирает установщик.

## Выпуск обновления

Укажи новую версию в `src-tauri/tauri.conf.json`, закоммить изменения и отправь тег с той же версией, например `v1.2.0`. GitHub Actions соберёт и подпишет установщик Windows x64, добавит `latest.json` и опубликует релиз. Для подписи используются секреты `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Храни резервную копию ключа и пароля: установленные клиенты проверяют обновления по публичному ключу из конфигурации.

Пользователи старых версий устанавливают первую сборку с автообновлением вручную. Дальше seWer проверяет обновления при запуске и каждый час. В разделе **Настройки → О приложении** можно проверить версию вручную или установить доступное обновление.
