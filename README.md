## Хотишь сам собрать?

Нужен **Node.js 18+**, **Rust** и **MSVC Build Tools**.

```
git clone https://github.com/despoyledporcelain/sewer-tauri.git
cd sewer-tauri
npm install
npm run app:dev
```
